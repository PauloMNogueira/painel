Comandos

Maquete: arraste para girar, pinça/roda para zoom, dois dedos ou botão direito para mover.
Visita: joystick no canto esquerdo para andar e arraste no resto da tela para olhar. No computador: W A S D ou setas, e arraste com o mouse. Shift corre. Os botões de cômodo levam direto para lá.
